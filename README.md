# Hoop Hop

Аркадный баскетбол в одно касание: прыгай мячом и пролетай сквозь кольца сверху вниз, собирай комбо, открывай скины, следы и арены.

## Файлы
- `index.html` — игра (без панели разработчика).
- `dev.html` — та же игра с панелью разработчика (кнопка DEV в меню) для тестов.

Всё в одном файле, сборка не нужна.

## Как выложить на GitHub Pages
1. Создай репозиторий, например `hoop-hop`, и загрузи в корень `index.html`, `dev.html`, `README.md`.
2. Settings → Pages → Source: **Deploy from a branch**, ветка `main`, папка `/ (root)` → Save.
3. Через 1–2 минуты игра будет по адресу `https://<логин>.github.io/hoop-hop/`, тестовая версия — `.../hoop-hop/dev.html`.

## Управление
Тап по экрану / Пробел — прыжок. Esc или P — пауза.

## Примечание
Это версия без SDK Яндекс Игр: реклама за вознаграждение здесь засчитывается сразу, прогресс хранится в браузере.
